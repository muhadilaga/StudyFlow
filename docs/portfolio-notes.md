# StudyFlow Portfolio Notes

## Elevator pitch
StudyFlow adalah planner akademik ringan untuk mahasiswa Indonesia yang menggabungkan jadwal kuliah, tugas, deadline, dan goal belajar mingguan ke dalam satu dashboard.

## Value proposition
Banyak mahasiswa menyimpan jadwal, tugas, dan target belajar di tempat yang terpisah. StudyFlow mencoba menyederhanakan itu menjadi satu alur yang cepat dipakai dari HP.

## Differentiators
- mobile-first UX
- Supabase Auth + RLS untuk keamanan dasar yang baik
- real CRUD flow untuk course, assignment, dan goal
- dashboard dengan indikator deadline dan tugas terlambat
